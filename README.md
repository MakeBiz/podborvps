Репозиторий сайта и монитора цен


# Инструкция: как всё поднять

Ничего программировать не нужно, всё делается мышкой в браузере. Займёт минут двадцать, из них половина это ожидание писем с подтверждением

## Шаг 1. Аккаунт на GitHub

GitHub это бесплатное хранилище файлов проекта. Он нужен по двум причинам: Vercel будет сам обновлять сайт при любом изменении файла, а монитор цен будет там же запускаться по расписанию, тоже бесплатно

Регистрация на `github.com`, кнопка Sign up. Достаточно личного аккаунта, платить не нужно: приватные репозитории и запуск задач по расписанию входят в бесплатный тариф

Альтернативы GitLab и Bitbucket Vercel тоже поддерживает, но у GitHub бесплатный планировщик задач удобнее, а инструкция ниже написана под него

## Шаг 2. Создать репозиторий

Репозиторий это просто папка проекта на GitHub

1. Справа вверху плюсик, `New repository`
2. Repository name: `podborvps`
3. Выбрать `Private`, чтобы содержимое видели только вы
4. Ничего не отмечать в блоке «Initialize this repository», галочки не нужны
5. `Create repository`

## Шаг 3. Загрузить файлы

На странице пустого репозитория есть ссылка `uploading an existing file`

1. Распаковать архив, который я прислал
2. Открыть папку `podborvps` и выделить всё, что внутри
3. Перетащить в окно браузера
4. Внизу кнопка `Commit changes`

**Если папка `.github` не загрузилась** (браузеры иногда пропускают папки, начинающиеся с точки), это чинится вручную за минуту:

1. `Add file`, затем `Create new file`
2. В поле имени вписать целиком: `.github/workflows/prices.yml`, слэши сами создадут папки
3. Вставить содержимое файла `prices.yml` из архива
4. `Commit changes`

## Шаг 4. Подключить Vercel

1. На `vercel.com` нажать `Add New`, затем `Project`
2. `Import Git Repository`, разрешить доступ к GitHub, выбрать `podborvps`
3. Настройки не трогать, файл `vercel.json` уже говорит Vercel публиковать папку `public`
4. `Deploy`

Через минуту сайт живой на адресе вида `podborvps.vercel.app`

**С этого момента всё автоматически.** Меняете файл в репозитории, Vercel сам пересобирает сайт за 30 секунд. Никаких ручных заливок больше не будет

## Шаг 5. Привязать домен

1. В проекте на Vercel: `Settings`, затем `Domains`, затем `Add`
2. Ввести домен, Vercel покажет, какие записи прописать у регистратора
3. Обычно это A-запись корня на `76.76.21.21` и CNAME для `www` на `cname.vercel-dns.com`
4. У регистратора эти записи вносятся в разделе управления DNS
5. Сертификат Vercel выпустит сам, обычно за пять минут, иногда до часа

## Шаг 6. Запустить монитор цен

Монитор уже лежит в репозитории и настроен на ежедневный запуск в 07:00 по Москве. Осталось выдать ему ключи

Токены заводятся бесплатно на обычных аккаунтах провайдеров:

| Провайдер | Где взять токен | Имя секрета |
|---|---|---|
| Timeweb Cloud | панель, Настройки, «API и Terraform», срок жизни выбрать бессрочный | `TIMEWEB_TOKEN` |
| VDSina | получить через запрос авторизации, см. их документацию по API | `VDSINA_TOKEN` |
| Reg.ru | панель Рег.Облака, раздел с токенами API | `REGRU_CLOUDVPS_TOKEN` |
| RUVDS | настройки аккаунта, API-ключ | `RUVDS_KEY`, плюс `RUVDS_USER` и `RUVDS_PASS` |
| Hostman | панель управления, раздел API | `HOSTMAN_TOKEN` |
| DataPacket | клиентская панель, Security, можно создать ключ только на чтение | `DATAPACKET_TOKEN` |

Как их положить в GitHub:

1. Репозиторий, вкладка `Settings`
2. Слева `Secrets and variables`, затем `Actions`
3. `New repository secret`, имя из таблицы, значение это сам токен
4. Повторить для каждого

Отдельно там же на вкладке `Variables` создать `FX_RATES` со значением:

```
{"USD":92,"EUR":100,"AED":25}
```

Это курсы для пересчёта долларовых тарифов в рубли, обновлять раз в месяц

**Проверить, что работает:** вкладка `Actions`, слева «Мониторинг цен», справа кнопка `Run workflow`. Через минуту в папке `monitor/data` появится файл с ценами. Если какой-то источник не отдал данные, GitHub сам заведёт задачу с описанием проблемы

Токены можно добавлять по одному: монитор работает с теми источниками, ключи к которым есть, остальные просто пропускает

## Что важно знать про тарифы

**Vercel.** Бесплатный план Hobby по правилам сервиса рассчитан только на личные некоммерческие проекты. Наш сайт зарабатывает на партнёрских ссылках, то есть формально коммерческий, и по-хорошему требует план Pro за 20 долларов в месяц. На старте можно спокойно тестировать на бесплатном, но закладывайте, что при росте придётся либо перейти на Pro, либо переехать

**Альтернатива, которая может оказаться выгоднее.** Сайт можно держать на VPS Timeweb за 300-600 рублей в месяц. Дешевле Pro, сервер в России, что лучше для скорости у российской аудитории, и заодно получается собственный кейс для контента: мы рекомендуем провайдера, которым сами пользуемся. Минус в том, что сервер надо обслуживать самому, тогда как Vercel не требует вообще ничего

**GitHub.** Приватные репозитории и 2000 минут запуска задач в месяц бесплатны. Наш монитор тратит меньше минуты в день, то есть около 30 минут в месяц. В бесплатный лимит укладываемся с большим запасом

## Как потом вносить правки

Не нужно ничего скачивать и устанавливать:

1. Открыть файл в репозитории на GitHub
2. Нажать карандаш
3. Поправить, нажать `Commit changes`
4. Vercel сам обновит сайт через полминуты

Так же правятся цены в мониторе, тексты на сайте и расписание запуска
